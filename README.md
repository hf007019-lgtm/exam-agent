> Exam Agent 不是给聊天界面套一层招考提示词，而是把可核验的结构化数据工具与 Agent 分析能力组合起来：数据由确定性流程检索、清洗和聚合，LLM 负责理解问题、组织解释与提示风险。

## 项目简介

Exam Agent 是一个面向公务员、省考、国考、事业单位等招考场景的本地 AI 数据分析工作台。

它将格式复杂的招考 Excel / CSV 清洗为可核验的结构化数据，再由 Agent 结合岗位表、进面分数线、报名缴费数据、资格复审样本和用户画像，生成岗位分析、分数参考与风险提示。

项目强调：

* **本地优先**：数据默认存储在本地 SQLite，不依赖云端数据库。
* **来源透明**：岗位、分数、报名人数等信息均来自已导入的数据集。
* **结论可核验**：AI 只负责辅助解释，不替代官方公告、职位表和资格审查。
* **隐私保护**：姓名、准考证号、身份证号、手机号等个人敏感信息默认不进入普通展示和 Agent 分析。

当前仓库为 **公开展示版 / 本地运行版**。

* 不包含真实招考数据、考生名单、SQLite 数据库或 API Key。
* 支持用户在本地上传合法来源的数据文件进行导入和分析。
* 核心链路已完成：数据导入 → 清洗预览 → 数据中心 → Agent 岗位分析。
* 仍处于持续优化阶段，暂未提供线上演示环境。
* 公开部署前仍需要补充认证授权、文件隔离、日志脱敏、接口限流和数据保留策略。

## 为什么做这个项目

真实选岗通常不是简单问一句“推荐岗位”就能解决。

用户往往需要同时查看：

* 职位表
* 进面分数线
* 报名人数 / 缴费人数
* 资格复审名单
* 候选人成绩表
* 专业目录
* 招考公告和报考指南

而不同省份、不同年份的 Excel 格式差异很大，经常出现：

* 多 Sheet
* 合并表头
* 多行表头
* 字段别名
* 空行和汇总行
* 岗位、分数、报名人数混在同一个表里
* 部分数据没有职位代码，只能弱匹配

Exam Agent 希望补上“数据准备”和“智能分析”之间的断层：**先把招考数据清洗成可核验的事实，再让 Agent 在事实基础上回答问题。**

## 核心能力

### 数据导入与清洗

支持 Excel / CSV 文件导入，并对真实招考表格中的复杂结构进行处理：

* 多 Sheet 识别
* 表头行识别
* 字段别名映射
* 清洗预览
* 异常行提示
* 重复记录检测
* 未映射字段保留
* 人工确认后入库

支持的数据类型包括：

| 数据类型       | 说明                              |
| ---------- | ------------------------------- |
| 岗位表        | 职位代码、招录单位、岗位名称、招录人数、学历、专业、备注等   |
| 进面分数线表     | 最低进面分、最高分、平均分、进面人数等             |
| 报名 / 缴费人数表 | 报名人数、审核人数、缴费人数、竞争比等             |
| 资格复审名单     | 入围人员成绩样本，默认隐藏个人敏感信息             |
| 候选人成绩表     | 候选成绩样本，默认仅做聚合参考                 |
| 专业目录表      | 专业名称、专业类别、学历层次等                 |
| 混合表        | 一个 Sheet 同时拆分出岗位、分数线、报名数据等多个数据集 |

---

### 一个 Sheet 多输出数据集

很多真实招考文件并不是“一个文件对应一张表”。

例如某些省考文件中，一个 Sheet 可能同时包含：

```text
职位代码
职位名称
招录单位
招录人数
缴费人数
最低进面分
最高进面分
```

Exam Agent 支持将同一个 Sheet 拆分为多个结构化数据集：

```text
岗位表 job_table
进面分数线表 score_line_table
报名 / 缴费人数表 signup_table
```

这样可以避免把混合表强行导成单一类型，减少字段错位和重复判断错误。

---

### 结构化数据中心

导入后的数据可以在数据中心在线查看和核对：

* 按数据集分组查看
* 分页加载
* 关键词搜索
* 查看清洗后字段
* 查看脱敏后的原表字段
* 统计数据集记录数
* 检查字段是否映射正确

数据中心的目标不是“展示好看表格”，而是让用户能确认：

```text
数据是否导进来了
字段是否清洗正确
敏感信息是否被隐藏
Agent 是否可以安全使用这些数据
```

### Agent 岗位分析

用户可以用自然语言提问：

```text
推荐几个广西南宁本科不限专业的岗位
分析 45050101 这个岗位
帮我比较这几个岗位哪个风险更低
我这个专业能报哪些岗位
```

Agent 会解析问题中的条件，例如：

* 省份
* 城市
* 学历
* 学位
* 专业
* 身份
* 政治面貌
* 基层经历
* 岗位代码
* 考试类型

然后调用结构化工具检索岗位、匹配分数线、读取报名数据，并生成岗位卡片。

---

### 岗位卡片

岗位分析结果以结构化卡片展示，而不是只返回一段自然语言。

卡片会尽量展示清洗后的公开字段：

* 职位代码
* 招录单位
* 岗位名称
* 招录人数
* 省份 / 地区
* 学历要求
* 学位要求
* 专业要求
* 身份要求
* 政治面貌
* 基层经历
* 资格条件
* 职位简介
* 咨询电话
* 单位地址
* 备注
* 官方进面分
* 进面人数
* 报名 / 缴费人数
* 资格复审成绩样本
* 数据来源
* 风险提示

字段展示规则：

```text
有值就展示，没有值就不展示。
不展示大面积“暂无”。
不展示姓名、准考证号等个人敏感信息。
```

---

### 分数与报名数据参考

系统严格区分不同分数来源：

| 来源类型     | 含义           | 是否等同官方最低进面分 |
| -------- | ------------ | ----------- |
| 官方进面分数线  | 已导入的官方进面分数线表 | 是           |
| 资格复审成绩样本 | 资格复审名单中的成绩聚合 | 否           |
| 候选人成绩样本  | 候选成绩表中的成绩聚合  | 否           |
| 无分数数据    | 当前没有可参考分数    | 否           |

分数来源优先级：

```text
官方进面分数线
    ↓
资格复审成绩样本
    ↓
候选人成绩样本
    ↓
暂无分数参考
```

系统不会把资格复审样本或候选人成绩样本说成“官方最低进面分”。

## Agent 工作流

```text
用户问题
  ↓
意图识别
  ↓
解析省份、城市、学历、专业、岗位代码等条件
  ↓
调用结构化工具检索岗位
  ↓
匹配官方分数线 / 资格复审样本 / 候选成绩样本
  ↓
补充报名缴费数据与岗位限制
  ↓
生成岗位卡片
  ↓
输出风险提示、数据来源和免责声明
```

Agent 优先使用本地结构化工具查询事实。LLM 主要负责：

* 理解用户问题
* 组织回答结构
* 总结风险
* 解释筛选结果
* 生成自然语言建议

当数据缺失时，系统会明确说明，例如：

```text
当前缺少报名人数数据，仅能基于岗位条件和历史分数进行初步判断。
```

## 数据导入工作流

```text
招考 Excel / CSV
  ↓
读取 Sheet
  ↓
识别表头和表格类型
  ↓
字段映射与人工确认
  ↓
清洗预览
  ↓
检查有效行、异常行、重复行
  ↓
确认入库
  ↓
写入 SQLite 正式表
  ↓
数据中心在线核对
```

普通单表导入：

```text
岗位表 → exam_jobs
进面分数线表 → exam_score_lines
报名统计表 → exam_signup_stats
资格复审名单 → exam_review_candidates
候选成绩表 → exam_candidate_scores
专业目录表 → exam_major_catalog
```

混合表多输出：

```text
一个 Sheet
  ├─ 岗位表
  ├─ 进面分数线表
  └─ 报名 / 缴费人数表
```

## 数据安全

本项目默认不上传、不公开、不展示个人敏感数据。

### 默认忽略

以下内容不会进入公开仓库：

```text
.env
SQLite 数据库
真实 Excel / CSV
data/
raw_private/
uploads/
logs/
缓存文件
本地导入文件
```

### 默认隐藏

以下字段不会在普通页面和 Agent 分析结果中展示：

```text
姓名
准考证号
身份证号
手机号
candidate_name
candidate_no
raw_row_json
单条个人成绩明细
```

### 可以展示的公开字段

以下属于岗位公开信息，可以展示：

```text
招录单位
职位代码
岗位名称
招录人数
职位简介
咨询电话
单位地址
学历要求
专业要求
政治面貌
资格条件
官方进面分
报名缴费人数
```

### 安全边界

本项目提供隐私保护的默认设计，但数据使用者仍需确保：

* 数据来源合法
* 数据使用目的明确
* 不上传未经授权的个人信息
* 不将真实考生名单提交到公开仓库
* 公开部署前补充权限控制、上传隔离、日志脱敏和接口限流

## 快速开始

建议使用 Python 3.11+。

### 1. 克隆项目

```bash
git clone https://github.com/hf007019-lgtm/exam-agent.git
cd exam-agent
```

### 2. 创建虚拟环境

Windows PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

macOS / Linux：

```bash
python -m venv .venv
source .venv/bin/activate
```

### 3. 安装依赖

```bash
python -m pip install -r requirements.txt
```

### 4. 创建本地配置

Windows PowerShell：

```powershell
Copy-Item .env.example .env
```

macOS / Linux：

```bash
cp .env.example .env
```

### 5. 启动服务

```bash
uvicorn app.main:app --host 127.0.0.1 --port 18100 --reload
```

打开工作台：

```text
http://127.0.0.1:18100/
```

API 文档：

```text
http://127.0.0.1:18100/docs
```

## 环境变量

完整示例见 [`.env.example`](.env.example)。

| 变量               | 用途                       | 说明                          |
| ---------------- | ------------------------ | --------------------------- |
| `DATABASE_URL`   | SQLite 数据库地址             | 默认使用本地 `data/exam_agent.db` |
| `AUTH_ENABLED`   | 是否启用本地认证                 | 本地开发可设为 `false`             |
| `JWT_SECRET_KEY` | JWT 签名密钥                 | 部署时必须更换                     |
| `LLM_BASE_URL`   | OpenAI-compatible API 地址 | 可选                          |
| `LLM_API_KEY`    | LLM API 密钥               | 不得提交到仓库                     |
| `LLM_MODEL_NAME` | 模型名称                     | 可选                          |
| `RAG_ENABLED`    | 是否启用外部政策检索               | 可选                          |
| `RAG_BASE_URL`   | 外部政策服务地址                 | 可选                          |

未配置 LLM 时，系统仍可通过规则兜底完成部分岗位筛选与结构化分析。

## API 示例

### Agent 分析

```bash
curl -X POST "http://127.0.0.1:18100/api/v1/agent/analyze" \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "job_recommendation",
    "exam_type": "省考",
    "region": "广西",
    "city": "南宁",
    "education": "本科",
    "major": "计算机类",
    "question": "推荐几个专业条件匹配的岗位，并说明风险"
  }'
```

### 数据导入

```bash
curl -X POST "http://127.0.0.1:18100/api/v1/imports/upload" \
  -F "file=@sanitized-example.xlsx" \
  -F "province=广西" \
  -F "exam_type=省考" \
  -F "year=2026"
```

请仅使用合法来源且已经脱敏的本地文件。

* 公务员、事业单位岗位初筛

* 自动代报名

## 贡献

欢迎提交 Issue 与 Pull Request。

参与贡献前，请先阅读 [CONTRIBUTING.md](CONTRIBUTING.md)。提交内容请确保：

* 不包含真实招考数据
* 不包含个人敏感信息
* 不包含 `.env`、数据库、Excel、CSV 等本地文件
* 修改说明清楚，便于 review

## 免责声明

本项目仅用于招考信息整理、数据分析与辅助决策。岗位推荐、历史分数参考、报名热度分析和 AI 风险提示不构成报考建议、录用承诺或资格审查保证。

招考政策、岗位条件、专业目录、报名人数和进面分数可能随时间变化。最终请以官方公告、职位表、报考指南、专业目录及招录单位解释为准。
