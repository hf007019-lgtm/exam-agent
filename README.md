# Exam Agent 招考数据智能分析工作台

面向公务员、省考、国考、事业单位等招考场景的 AI 数据分析与岗位决策辅助系统。

从招考 Excel 到结构化数据，从岗位筛选到分数参考，从报名热度到 AI 风险提示，Exam Agent 试图把“查表、清洗、对比、分析”整合到一个可本地运行的工作台中。

</div>

---

## 项目简介

Exam Agent 是一个面向招考数据的 AI 决策分析工作台，主要服务于公务员、省考、国考、事业单位等招考场景。

传统选岗通常需要人工反复查看职位表、进面分数线、资格复审名单、报名人数和公告政策。不同省份的数据格式不统一，Excel 表格经常存在多 Sheet、合并表头、字段命名混乱、岗位信息和分数信息混在一起等问题，导致普通用户很难快速完成岗位初筛和风险判断。

本项目围绕“招考数据导入、清洗、查看、分析、辅助决策”构建完整流程：

```text
招考 Excel / CSV
        ↓
自动识别 Sheet 与表格类型
        ↓
字段映射与清洗预览
        ↓
写入本地结构化数据库
        ↓
数据中心在线核对
        ↓
Agent 结合岗位、分数、报名数据进行分析
        ↓
输出岗位卡片、风险提示与数据来源说明
```

项目强调谨慎、透明和可核验：

* AI 分析只做辅助参考，不替代官方公告。
* 历史分数仅作为风险参考，不代表当年分数线。
* 资格复审名单成绩样本不等同于官方最低进面分。
* 数据缺失时明确提示，不编造分数、竞争比或政策依据。
* 默认隐藏姓名、准考证号、身份证号、手机号等个人敏感信息。

## 核心能力

### 1. 招考分析师

支持自然语言提问，例如：

```text
推荐几个广西南宁本科不限专业的岗位
分析 45050101 这个岗位
帮我比较这几个岗位哪个风险更低
我这个专业能报哪些岗位
```

Agent 会结合结构化岗位数据、官方分数线、资格复审样本、报名缴费数据和用户画像进行分析，并以岗位卡片形式展示结果。

### 2. 数据导入工作台

支持本地上传 Excel / CSV，并进行清洗预览和人工确认。

当前支持的数据类型包括：

* 岗位表
* 进面分数线表
* 资格复审名单
* 候选人成绩表
* 报名 / 审核 / 缴费人数表
* 专业目录表
* 岗位 + 报名人数 + 进面分数混合表

导入流程支持：

* 多 Sheet 识别
* 表头行识别
* 字段映射
* 低置信度人工确认
* 清洗预览
* 重复记录提示
* 未映射字段保留
* 多输出数据集拆分

例如，一个浙江省考混合表可以从同一个 Sheet 同时生成：

```text
job_table          岗位表
score_line_table   进面分数线表
signup_table       报名 / 缴费人数表
```

### 3. 数据中心

导入后的数据可以在数据中心在线查看，包括：

* 数据集类型
* 数据年份
* 省份
* 考试类型
* 记录数量
* 清洗后字段
* 分页查看
* 关键词搜索
* 原表字段脱敏查看

数据中心用于核对清洗结果，避免“导入成功但字段错位”的问题。

### 4. 岗位分析卡片

Agent 分析结果不是简单文本，而是结构化岗位卡片。卡片会尽量展示清洗后的公开字段：

* 职位代码
* 招录单位
* 岗位名称
* 招录人数
* 省份 / 地区
* 学历要求
* 学位要求
* 专业要求
* 身份要求
* 政治面貌
* 基层经历
* 资格条件
* 职位简介
* 咨询电话
* 单位地址
* 备注
* 官方进面分
* 进面人数
* 资格复审成绩样本
* 报名 / 缴费人数
* 数据来源
* 风险提示

字段展示遵循：

```text
有值就展示，没有值就不展示。
不展示大面积“暂无”。
不展示个人敏感信息。
```

### 5. 分数参考与风险判断

系统区分不同分数来源：

| 来源类型     | 含义           | 是否等同官方最低进面分 |
| -------- | ------------ | ----------- |
| 官方进面分数线  | 已导入的进面分数线表   | 是           |
| 资格复审成绩样本 | 资格复审名单中的成绩聚合 | 否           |
| 候选人成绩样本  | 候选人成绩表中的成绩聚合 | 否           |
| 无分数数据    | 当前没有可参考分数    | 否           |

展示顺序优先级：

```text
官方进面分数线
    ↓
资格复审成绩样本
    ↓
候选人成绩样本
    ↓
暂无分数参考
```

### 6. 用户画像与多轮分析

系统支持记录用户的长期条件，例如：

* 目标省份
* 目标城市
* 学历
* 学位
* 专业
* 身份条件
* 政治面貌
* 基层经历

Agent 可以结合这些画像进行岗位筛选和推荐。

## Agent 分析流程

```text
用户问题
  ↓
意图识别
  ↓
解析省份、城市、学历、专业、岗位代码等条件
  ↓
调用结构化工具检索岗位
  ↓
匹配官方分数线 / 资格复审样本 / 候选成绩样本
  ↓
补充报名缴费数据与岗位限制
  ↓
生成岗位卡片
  ↓
输出风险提示、数据来源和免责声明
```

Agent 不直接“拍脑袋”推荐岗位，而是优先依赖本地已导入的结构化数据。缺少数据时会明确说明，例如：

```text
当前缺少报名人数数据，仅能基于岗位条件和历史分数进行初步判断。
```

## 数据导入流程

```text
上传 Excel / CSV
    ↓
读取 Sheet
    ↓
自动判断表格类型
    ↓
用户确认类型和字段映射
    ↓
清洗前 20 行预览
    ↓
检查有效行、异常行、重复行
    ↓
确认入库
    ↓
写入 SQLite 正式表
    ↓
数据中心在线查看
```

### 支持普通单表

例如：

```text
岗位表 → exam_jobs
进面分数线表 → exam_score_lines
资格复审名单 → exam_review_candidates
报名人数表 → exam_signup_stats
专业目录表 → exam_major_catalog
```

### 支持混合表多输出

例如一个 Sheet 同时包含：

```text
职位代码
职位名称
招录单位
招录人数
缴费人数
最低进面分
最高进面分
```

系统可以拆成：

```text
岗位表
进面分数线表
报名 / 缴费人数表
```

## 快速开始

### 1. 克隆项目

```bash
git clone https://github.com/hf007019-lgtm/exam-agent.git
cd exam-agent
```

### 2. 创建虚拟环境

Windows PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

macOS / Linux：

```bash
python -m venv .venv
source .venv/bin/activate
```

### 3. 安装依赖

```bash
python -m pip install -r requirements.txt
```

### 4. 创建本地配置

```bash
cp .env.example .env
```

Windows PowerShell：

```powershell
Copy-Item .env.example .env
```

### 5. 启动服务

```bash
uvicorn app.main:app --host 127.0.0.1 --port 18100 --reload
```

### 6. 打开工作台

```text
http://127.0.0.1:18100/
```

API 文档：

```text
http://127.0.0.1:18100/docs
```

## 项目特点

### 1. 面向真实招考数据格式

项目不是只处理干净的示例 JSON，而是围绕真实招考 Excel 常见问题设计：

* 多 Sheet
* 合并表头
* 字段别名
* 岗位和分数混合
* 资格复审名单
* 报名缴费人数
* 缺字段
* 重复记录
* 人工确认

### 2. 结构化工具优先，LLM 负责解释

岗位、分数、报名数据由确定性工具检索和聚合，LLM 主要负责：

* 解释筛选结果
* 总结风险
* 生成自然语言建议
* 组织岗位对比理由

避免让 LLM 直接编造结构化事实。

### 3. 分数来源分层

系统严格区分：

```text
官方进面分数线
资格复审成绩样本
候选人成绩样本
暂无分数数据
```

并在页面中标注来源和限制。

### 4. 数据安全优先

项目默认不提交真实数据，不展示个人敏感信息，并在 README、页面和数据中心中提示数据安全边界。

## 注意事项

1. 本仓库不包含真实招考数据。
2. 本仓库不包含真实考生个人信息。
3. 本仓库不包含本地 SQLite 数据库。
4. 使用者需要自行准备合法来源的数据文件。
5. AI 分析仅供参考，不能代替官方公告、职位表和资格审查结果。
6. 如需公开部署，应进一步增加权限控制、上传文件隔离、日志脱敏和接口限流。

本项目仅用于招考信息整理、数据分析和决策辅助。项目输出的岗位推荐、历史分数参考、报名热度分析和 AI 风险提示均不构成报考建议、录用承诺或资格审查保证。
