# 数据导入指南

## 支持的数据类型

系统支持上传 `.xlsx`、`.xls` 和 `.csv`，并识别以下招考数据：

- 岗位表 / 职位计划表
- 官方进面分数线或岗位分数参考
- 候选成绩、面试入围或资格复审名单
- 报名人数、审核通过人数、缴费人数和竞争比
- 专业目录

原始文件只在本地使用。真实文件、导入缓存和生成的 SQLite 均不应提交到公开仓库。

## 导入流程

1. 在工作台数据导入入口选择本地文件。
2. 系统读取工作簿中的 Sheet，识别表头、数据起始行和候选数据类型。
3. 用户确认目标 Sheet、数据类型和字段映射。
4. 系统展示清洗预览、有效行、重复行、异常行和阻断原因。
5. 用户确认后，结构化记录写入本地 SQLite。
6. 在数据中心查看数据集范围和清洗结果；必要时可删除指定数据集。

对应 API 包括：

- `POST /api/v1/imports/upload`
- `GET /api/v1/imports/{task_id}/preview`
- `POST /api/v1/imports/{task_id}/remap`
- `POST /api/v1/imports/{task_id}/confirm`
- `GET /api/v1/imports/datasets/{dataset_id}/rows`

## 字段映射

导入器把不同来源的中文表头映射为内部标准字段。例如：

| 业务含义 | 常见来源字段 | 标准字段示例 |
| --- | --- | --- |
| 职位代码 | 职位代码、岗位代码、招录职位 | `job_code` |
| 单位 | 招录机关、用人单位、部门名称 | `unit_name` |
| 岗位名称 | 职位名称、岗位名称 | `job_name` |
| 招录人数 | 计划人数、招考人数 | `recruit_count` |
| 最低进面分 | 最低分、最低入围分 | `min_score` |
| 报名/缴费 | 报名人数、审核人数、缴费人数 | `signup_count` / `paid_count` |

自动映射不等于业务事实确认。字段缺失、同名歧义或异常表头应在预览阶段人工核对。

## 多 Sheet 与多输出

- 多 Sheet：读取工作簿中的多个 Sheet，按结构和数据类型判断可处理内容；用户可指定目标 Sheet。
- 多输出：当同一 Sheet 同时包含岗位、报名缴费和分数列时，可从一套可信表头生成多个独立数据集。
- 每个输出拥有独立字段映射、有效行和警告信息，确认前不会混写到业务表。

## 敏感信息处理

- 姓名、准考证号等字段可用于识别名单结构和本地去重，但默认不在普通数据视图展示。
- 敏感字段不进入 Agent 岗位分析上下文，也不用于岗位推荐。
- 不要把身份证号、手机号、考生名单或未经授权的原始文件复制到 `sample_data/`。
- 公开示例必须完全虚构或经过不可逆脱敏，并在提交前再次扫描。
