# Agent 分析逻辑

## 总体流程

```text
用户问题 + 筛选条件 + 我的画像 + 最近对话
  → 意图与工具判断
  → 岗位 / 分数 / 政策 / 风险工具（按需）
  → 结构化事实校验与数量限制
  → LLM 解释或规则兜底
  → 文本回答 + 可选岗位卡片
```

普通咨询直接回答，不调用岗位工具。明确的推荐、筛选、单岗、分数或政策问题才读取对应数据。LLM 只能解释工具结果，不能修改岗位、省份、年份、分数匹配类型或缺失状态。

## 岗位分析

单岗位分析优先回答是否值得加入备选，再解释：

1. 学历、专业、身份等资格匹配。
2. 地区、单位和岗位方向适配。
3. 招录人数及已知报名数据。
4. 历史分数参考与匹配可信度。
5. 额外条件和仍需核验的数据缺口。

只招 1 人时提示结果波动；公安、人民警察、司法等岗位提示体检、体测、政审、年龄或专业测试等额外要求。缺少竞争或分数数据时，不使用“稳”等判断。

## 分数来源优先级

岗位分数匹配按以下顺序处理：

1. 职位代码精确匹配。
2. 职位代码标准化后或可信局部代码匹配。
3. 单位 + 岗位名称 + 年份 + 省份的高置信匹配。
4. 同类岗位历史参考。
5. 无匹配。

只有高置信结果可以称为该岗位历史进面分。同类参考必须明确标注“非该岗位精确进面分”。

## 不同成绩数据的区别

- 官方分数线：由官方按岗位或类别发布，含义最明确，但仍只代表对应年份。
- 资格复审/面试入围样本：记录进入某个后续环节的人员或成绩，可帮助观察样本范围，但未必覆盖全部人员，也未必等同官方最低线。
- 候选成绩样本：可能来自部分名单、汇总表或二次整理，只能作为样本证据。

## 为什么不能把样本最低分当作官方最低进面分

样本可能缺行、筛选过、跨岗位合并，或只包含某个地区和环节。样本中的最小值只是“当前样本最小值”，不能证明它是官方完整口径下的岗位最低进面分。把两者混用会制造虚假的精确性，因此系统必须保留来源类型、匹配类型和数据缺口。

所有分析最终以官方公告、职位表、报考指南和资格审查为准。
