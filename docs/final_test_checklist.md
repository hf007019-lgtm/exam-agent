# 最终测试检查清单

本清单用于发布前人工或自动化验收。只有实际执行并记录结果后，才能标记通过。

## 数据导入

- [ ] `.xlsx`、`.xls`、`.csv` 均能进入预览流程。
- [ ] 多 Sheet 文件可选择目标 Sheet，跳过项有明确原因。
- [ ] 岗位、进面分、资格复审/候选成绩、报名缴费和专业目录能正确识别。
- [ ] 混合表可生成多个独立输出，字段映射互不污染。
- [ ] 重复行、异常数值、必填字段缺失和阻断原因显示清楚。
- [ ] 确认前不写入正式业务表，确认后数据集统计正确。

## 数据中心

- [ ] 可查看数据集年份、省份、类型、记录数和清洗结果。
- [ ] 岗位数据与分数数据覆盖范围分开展示。
- [ ] 不显示内部 CSV 文件名、绝对路径或 debug 字段。
- [ ] 数据集删除只影响指定本地数据集。

## 岗位与 Agent 分析

- [ ] 普通方法论问题不显示岗位卡片。
- [ ] 推荐默认最多 5 个；要求 1 个或 3 个时服从该上限。
- [ ] 单岗位查询支持职位代码、岗位名称和单位名称。
- [ ] 岗位卡片展示公开条件、历史分数语义、已知报名数据和风险提示。
- [ ] 无精确分数时不绑定无关参考；同类参考明确标注非精确值。
- [ ] 缺少报名人数、竞争比或进面分时不出现“稳”等判断。
- [ ] 政策检索无来源时明确降级，并提醒核对官方文件。
- [ ] 多轮消息、筛选器和画像条件持续传入分析请求。

## 敏感信息

- [ ] Git 跟踪文件和 Git 历史中不存在 `.env`、数据库、真实 Excel/CSV。
- [ ] 示例数据不含真实姓名、准考证号、身份证号、手机号或可识别组合。
- [ ] 数据中心、岗位卡片、分析记录和 API 普通响应不展示敏感字段。
- [ ] 日志、异常信息和文档不包含密钥、内部路径或原始上传文件名。

## 页面与可访问性

- [ ] 九个一级页面可进入，空状态、加载、成功和错误状态完整。
- [ ] 375、768、1024、1440px 下无页面级横向滚动或遮挡。
- [ ] 宽对比表只在独立容器中横向滚动。
- [ ] 键盘可操作，`:focus-visible` 清楚，表单标签完整。
- [ ] 触控目标满足约 44×44px，移动端输入字号不小于 16px。
- [ ] `prefers-reduced-motion` 下无不必要动画。

## 发布检查

- [ ] 执行项目测试并记录版本、命令和结果。
- [ ] 执行 `git status --ignored` 和 `git ls-files`。
- [ ] 扫描 Git 历史中的密钥和真实数据对象。
- [ ] 确认未修改外部 `rag_builder`，未上传 `raw_private/`。
- [ ] 获得明确确认后再暂存、提交或推送。
